# 偏倚風險工具：改編 QUADAS-2（D2）

依 `protocol/protocol.md` 3.8（2026-11-14 確認）。參照 QUADAS-2（Whiting et al., Ann Intern Med 2011）的領域結構與 TRIPOD-LLM 的報告項目。`extraction/risk_of_bias.xlsx` 由 `scripts/make_rob_form.py` 依本檔產生。

## 評估單位與流程
- 以**研究**為單位；研究有多個任務時，以主要任務（摘要中最先報告者）評估，其他任務若判斷不同則在 `note` 說明。
- 每個信號問題回答 `Y`（是）／`N`（否）／`U`（不清楚）／`NA`。
- 每個領域判定：**Low**（所有信號問題為 Y 或 NA）、**High**（任一信號問題為 N 且判斷者認為足以影響結果）、**Unclear**（有 U 且無 N 達 High）。判定理由與原文頁碼寫在 `D*_rationale`。
- 另外判定**適用性疑慮**（applicability concern：Low／High／Unclear）於領域 1、2：研究的文本、任務、參考標準是否與本回顧問題相符。
- Agent 先預評並附理由與原文頁碼，作者逐篇逐領域複核並做最終判斷（2026-11-14：單一作者，不設第二位評估者）。
- **整體**：四領域皆 Low → Low；任一 High → High；其餘 → Unclear。敏感度分析 (b) 排除整體為 High 的研究。

## 領域 1：資料與樣本
| 代號 | 信號問題 |
|---|---|
| 1.1 | 測試文本的來源與選取方式是否有描述（例如連續取樣或隨機取樣，而非挑選的案例）？ |
| 1.2 | 測試集是否避免了不當的排除（例如排除難判讀或格式不佳的文件）？ |
| 1.3 | 測試集大小是否足以估計效能（有報告樣本數，且每個主要抽取目標的陽性例數可估）？ |
| 1.4 | 是否使用超過一個機構或外部資料進行評估？（單一機構不自動判 High，但需在理由中說明） |

適用性：測試文本類型、病歷語言、臨床情境是否與本回顧的臨床自由文本範圍相符？

## 領域 2：參考標準
| 代號 | 信號問題 |
|---|---|
| 2.1 | 參考標準是否由人工標註，或由可信的既有結構化資料產生並經驗證？ |
| 2.2 | 是否報告標註者人數與資格（例如臨床專業人員）？ |
| 2.3 | 是否報告標註者一致性，或有雙人標註＋仲裁？ |
| 2.4 | 標註指引是否有描述或公開？ |
| 2.5 | 參考標準是否在不知道模型輸出的情況下建立（避免以模型輸出為底稿修正）？ |

適用性：參考標準所定義的抽取目標是否與本回顧的資訊抽取定義相符？

## 領域 3：模型與評估流程
| 代號 | 信號問題 |
|---|---|
| 3.1 | 測試資料是否與 prompt 開發、few-shot 範例選取、微調、超參數調整所用資料分離？ |
| 3.2 | 若使用公開資料集（如 MIMIC、n2c2），是否討論或檢查了預訓練資料污染（contamination）的可能？（未使用公開資料集 → NA） |
| 3.3 | 是否事先指定 prompt／設定，或報告所有測試過的 prompt／設定，而非只報告測試集上最佳者？ |
| 3.4 | 模型版本、推論參數（temperature、解碼方式）是否有報告，足以重現？ |
| 3.5 | 所有測試文件是否都納入評估（未因輸出格式錯誤、超出 context 長度等原因而被剔除；若有剔除，是否計為錯誤）？ |

## 領域 4：分析
| 代號 | 信號問題 |
|---|---|
| 4.1 | 指標的定義是否清楚（評估層級、strict/lenient、micro/macro）？ |
| 4.2 | 是否報告變異（多次執行、信賴區間或標準差）？若模型以非決定性解碼執行而只跑一次，回答 N。 |
| 4.3 | 不同模型之間的比較是否公平：相同測試資料、相同評估方式、相近的調整投入？（無比較對象 → NA） |
| 4.4 | 結果段是否報告了方法段宣稱的所有評估（無選擇性報告；對應 protocol 3.10）？ |
